Это виджет, который показывает несколько последних успешных банковских операций клиента

Проект включает тесты для проверки корректности работы функций. Тесты находятся в каталоге tests/ и используют pytest.

Добавлены следующие функции:
**filter_by_currency** — фильтрация транзакций по валютному коду.
**transaction_descriptions** — извлечение описаний транзакций.
**format_number** — форматирование номера карты с пробелами через каждые четыре цифры.
**card_number_generator** — генерация номеров карт в заданном диапазоне.
# Запуск тестов:

Убедитесь, что pytest установлен:

    pip install pytest

Запустите тесты командой:

    pytest -v

Добавлен декоратор decorators и декоратор log который будет автоматически 
логировать начало и конец выполнения функции, а также ее результаты или возникшие ошибки.
